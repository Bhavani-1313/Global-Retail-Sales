# Global Retail Sales 

An interactive **Power BI business intelligence dashboard** developed to analyze global retail sales performance across products, regions, customers, profitability, and sales targets.

The dashboard transforms retail sales data into interactive visual insights that help understand revenue performance, profitability, regional contribution, product performance, and customer-segment trends.

## Overview

The **Global Retail Sales** provides a consolidated view of key business performance indicators and enables users to explore sales and profitability patterns through interactive Power BI visualizations.

The dashboard includes analysis of monthly sales trends, regional performance, product sales, profitability, discounts, customer segments, and sales manager performance.
